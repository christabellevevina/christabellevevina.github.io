# Christabelle Vevina — Architecture Portfolio

Personal architecture student portfolio website for Christabelle Vevina.

## Live website

This site is intended to be published at:

`https://christabellevevina.github.io/`

The GitHub repository must therefore be named exactly:

`christabellevevina.github.io`

## Publishing with GitHub Pages

1. Open the `christabellevevina.github.io` repository.
2. Upload all files and folders shown in the website structure above.
3. Confirm that `index.html` and the `assets` folder are visible directly in the repository's main Code page.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch and the `/ (root)` folder.
7. Click **Save**.
8. After deployment finishes, open `https://christabellevevina.github.io/`.

## Updating the website

Upload the revised files to the same repository and commit the changes. Keep the same filenames and folder structure so that image paths and project links continue to work.
